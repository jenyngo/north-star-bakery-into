# North Star Bakery — Touchstone 3

This project builds directly on the four-page North Star Bakery website from Touchstone Task 2.

## Files
- index.html
- products.html
- about.html
- contact.html
- styles.css
- North Star Bakery image, audio, and video assets

## Touchstone 3 design
- External CSS shared across all pages
- Four-color palette: #FFF8F0, #6B3E26, #D88C5A, #2F2A26
- Two font families: Georgia and Arial
- Mobile-first layout
- Flexbox navigation and page layout
- Media query at 800px
- Responsive images/media
- Accessible navigation, alt text, form labels, fieldset/legend, validation, and audio/video fallback text
